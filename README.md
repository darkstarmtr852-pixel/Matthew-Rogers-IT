# Matthew-Rogers-IT
Throughout this course I have made many changes fixes and other modifications to the code provided to me and I have learned a great deal of things and can't wait for what is next

My main objectives were to help users keep track of assignments, manage grades, and organize course materials. I focused on designing user-friendly interfaces, ensuring data was managed accurately, and building the 

essential features needed for successful course management.

As a student myself, I understand how challenging it can be to stay organized and monitor academic progress. I wanted my application to make it easier for users to input, update, and view assignments and grades. I 

also included tools for instructors to efficiently oversee student submissions and performance, hoping to make their workflow smoother as well.

believe one of my strengths was in using an iterative approach: I built the application in stages, sought feedback, and improved my design with each cycle. I paid special attention to keeping my code clean and 

modular, and I made sure to test thoroughly at every step. This approach made the application both reliable and easy to maintain.

Designing for both Console and WPF was an enlightening experience. The Console version offered simplicity and speed for users who prefer text-based interactions, while the WPF version allowed me to craft a visually 

engaging interface with intuitive navigation. I enjoyed leveraging WPF’s flexibility to create richer layouts and data validation, which made the app more accessible to a wider range of users.

I put a lot of thought into which screens and features would best support the people using my app. Dashboards for assignments and grades, clear entry forms, and summary views were all designed to be straightforward 

and efficient. I relied on user surveys and informal usability tests to refine the interface, always keeping the end-user’s perspective at the forefront. My focus on clarity and ease of use paid off—users found the 

app simple to navigate and effective for their needs.

During development, I made it a habit to use IDE debugging tools, conduct regular code reviews, and write unit tests. Version control helped me track changes and experiment without fear of losing progress. These 

habits not only helped me catch bugs quickly but also gave me confidence in the stability of my code. I intend to carry these strategies into all my future projects.

One of the areas where I had to innovate was with data binding in WPF, which made updating the UI far easier and reduced repetitive code. I also developed reusable components to streamline both the Console and WPF 

versions. When challenges arose—such as keeping data synchronized across screens or supporting multiple user roles—I relied on creative problem-solving and iteration to find effective solutions.

This project has been a rewarding journey, allowing me to grow as a developer and to appreciate the importance of user-centered design, good coding practices, and adaptability. I hope my application makes a positive 

difference for those who use it.
